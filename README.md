# FITLOG — Workout Tracker & Daily Fitness Planner

FITLOG is a modern, high-performance web application designed for fitness enthusiasts to build, organize, and track their daily workout routines. Built with Next.js and Tailwind CSS, FITLOG provides a sleek dark-themed interface with real-time stats and dynamic sorting capabilities.

---

## 🛠️ Technologies Used

- **Framework:** Next.js (App Router)
- **Library:** React
- **Styling:** Tailwind CSS
- **State Management:** React Context API (`FitLogContext`)
- **Typography:** Google Fonts (`Oswald`, `Geist`)
- **Image Optimization:** Next.js Image Component
- **Icons:** Inline SVG Icons

---

## ✨ Key Features

1. Daily Plan Add, View and Management
2. Saved Workouts Library
3. Dynamic Real-Time Sorting
4. Live Metrics Dashboard So, Automatically calculates and displays real-time stats for total exercises, active workout duration in minutes, and estimated calories burned.
5. Adaptive Responsive Layout. Custom responsive UI tailored specifically for both desktop and mobile devices.
6. One-Tap Completion & Removal.  Mark completed exercises as done or remove items with real-time stat updates.
